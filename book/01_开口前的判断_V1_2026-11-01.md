# 1. 开口前的 3 个判断

> 所有场景共用。任何一次重要沟通之前，先花 30 秒过一遍这三题。

<a id="h-31b3af237b37"></a>

## 1.1 三题

**第一题：对方现在最怕什么？**

不是"对方想要什么"。**怕**比**想**更能驱动人。

产品经理最常面对的三种怕：

| 对方 | 他最怕的 |
|---|---|
| 领导 | 交付不了 / 背锅 / 投入产出不划算 |
| 开发 | 需求反复改 / 加班 / 出问题算他的 |
| 业务方 | 客户找他麻烦 / 承诺了做不到 |
| 客户 | 花了钱没效果 / 被当成不重要的人 |

**第二题：我要的是一个"知道"，还是一个"动作"？**

- 要**知道**（他了解就行）→ 信息给全，结构清楚，不要压。
- 要**动作**（他必须做点什么）→ 说清楚"谁、做什么、什么时候之前"。

很多沟通失败，是因为你以为你要了动作，实际只传达了信息。

**第三题：这件事，我的底线在哪？**

想清楚：
- 最好的结果是什么？
- 最差能接受到哪一步？
- 到什么程度我就得升级/找人？

**底线没想清楚就开口，你会被一路推到墙角。**

<a id="h-f2a6a96e27a6"></a>

## 1.2 一句话核心句

任何沟通，先能憋出这一句：

> **【谁】需要【做什么】，以便【达到什么结果】**

写不出这句，说明你自己还没想清楚。**别开口，先想。**

<a id="h-210083ebe682"></a>

## 1.3 为什么表达会乱

| 毛病 | 长什么样 | 解药 |
|---|---|---|
| 想法碎片化 | 想到哪说到哪 | 先写一句核心句 |
| 跳跃式思维 | 前后没有因果 | 用一个固定结构（见 3.1） |
| 情绪干扰 | 夹带抱怨和委屈 | 去情绪化（见 3.1.5） |
| 没有结构 | 一堆并列信息 | 分类 + 排序 |

本质是：**大脑里是一张网，嘴里出来必须是一条线。** 表达的功夫，就是把网拆成线的功夫。

<a id="h-4db7ede06c11"></a>

## 1.4 沟通漏斗效应

你心里想的 100%，说出来只剩 80%，对方听到 60%，听懂 40%，做出来 20%。

```
心里想的   ████████████████████  100%
说出来的   ████████████████       80%   ← 表达能力漏掉 20%
对方听到   ████████████           60%   ← 注意力漏掉 20%
对方听懂   ████████               40%   ← 理解差异漏掉 20%
对方做到   ████                   20%   ← 执行环节漏掉 20%
```

**三个漏点的堵法：**

| 漏在哪 | 堵法 |
|---|---|
| 想的 → 说的 | 开口前写核心句（1.2） |
| 说的 → 听懂的 | 让对方复述一遍（2.2） |
| 听懂的 → 做到的 | 落到"谁、做什么、几号前"（4.5） |

<a id="h-6a96cf0dfadc"></a>

## 1.5 30 秒电梯法则

任何事，先准备一个 30 秒能说完的版本。

结构：**结论 + 一个数字 + 一个请求**

> "指标标准化目前录了三分之一，按这个速度年底完不成。我想跟编辑那边的负责人约个会，您能帮我引荐一下吗？"

三句话。结论、数字、请求。
