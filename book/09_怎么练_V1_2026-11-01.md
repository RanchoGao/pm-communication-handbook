# 9. 怎么练

> 前面八章是临场查的。这一章是平时练的。
> **只查不练，每次都是现翻现用，永远不会变成本能。**

<a id="h-3e47fbf27643"></a>

## 9.1 五个表达训练

> 每个训练每天 5 分钟，三天能看出变化。

<a id="h-e577c7e8c337"></a>

### 训练 1：三句话练习

**做法**：每天挑一件工作上发生的事，用三句话说完。

```
1. 发生了什么
2. 问题是什么
3. 解决建议是什么
```

**治什么**：治"说了半天说不到点上"。

> 例：
> "昨天的联调，接口返回的字段跟文档不一致。
> 导致前端要改三处，可能影响周四提测。
> 建议今天上午先拉个 15 分钟的会把字段定死。"

<a id="h-69e70405e130"></a>

### 训练 2：一句话总结练习

**做法**：读一段话（邮件、会议记录、需求描述），提炼出中心句。

**治什么**：治"抓不住重点"。抓不住别人的重点，也就说不出自己的重点。

> **判断标准**：你的中心句，能不能让没读原文的人明白这段话在说什么。

<a id="h-e6b7b66abd66"></a>

### 训练 3：结构化梳理练习

**做法**：任何一个观点，都用"**结论 + 3 个理由**"讲出来。

**治什么**：治"想到哪说到哪"。

> 为什么是 3 个？
> 1 个显得单薄，2 个不够稳，超过 3 个对方记不住。**3 是最好的数字。**

<a id="h-0c1344819658"></a>

### 训练 4：场景化表达练习

**做法**：讲任何一个需求，都用这四步：

```
场景 → 动机 → 阻碍 → 期望结果
```

**治什么**：治"从功能出发讲需求"。这是产品经理最常见的毛病。

> ❌ "我们要加一个批量导出功能。"
> ✅ "采购员月底对账（场景），想快速核对上月订单（动机），现在要一张张翻，一次两小时（阻碍），我们想让他一次导出十分钟对完（期望结果）。"

<a id="h-cbf2555a8748"></a>

### 训练 5：反向澄清练习

**做法**：拿到任何一个任务，先写两个清单：

```
【不明确的信息】
- ...
【我当前的假设】
- ...
```

**治什么**：治"默认大家都理解"。这是 [7.18](07_麻烦现场_V1_2026-11-01.md#h-91536cba13da) 那场争执的根。

**这个训练性价比最高。** 一份需求写完，花 5 分钟列一遍"我假设了什么"，能省掉后面两天的返工。

## 9.2 五条习惯

> 习惯比技巧重要。技巧要想，习惯不用想。

| 习惯 | 做法 | 花多久 |
|---|---|---|
| **每天一句核心句** | 当天最重要的那件事，用一句话写下来 | 1 分钟 |
| **每周复盘一次表达** | 这周哪一次沟通没说清楚？为什么？ | 10 分钟 |
| **会议前写结构大纲** | 开会前 5 分钟，写下"我要说的三件事" | 5 分钟 |
| **模糊内容先列问题清单** | 拿到模糊的东西，先写"我需要确认什么" | 5 分钟 |
| **所有沟通先结论** | 不管对谁、什么场合，第一句是结论 | 0 分钟 |

**最后一条是最重要的，也是唯一不花时间的。**

它唯一的难点是：**要忍住不先讲背景。** 大部分人讲不出结论，是因为讲背景让人有安全感。

## 9.3 项目管理沟通自检

> 这五个问题，每个项目开始前自己答一遍。答不上来的，就是风险点。

| # | 问题 | 答不上来意味着 |
|---|---|---|
| 1 | 这个项目的**里程碑计划**是什么？ | 你不知道什么时候该检查什么 |
| 2 | 质量、时间、预算，**这次优先保哪个**？ | 一旦冲突，你会做出错误的取舍 |
| 3 | 团队的**沟通机制**是什么？（谁、多久、同步什么） | 信息会在某个环节断掉 |
| 4 | 团队压力大、起冲突的时候，**我怎么处理**？ | 到时候只能凭情绪反应 |
| 5 | 这个项目最大的**三个风险**是什么？应对措施呢？ | 风险出现时你会措手不及 |

**第 2 题是最关键的。**

任何项目都不可能同时保住质量、时间、预算三样。**事前想清楚保哪个，事中才知道砍什么。**

> 事前跟领导确认一次：
> "这个项目，如果中间遇到冲突，您希望优先保时间还是保完整度？"
>
> 这一个问题，能省掉后面所有的扯皮。

## 9.4 怎么用这本手册练

**第一步：查（现在）**

遇到事，翻 [0.2 速查表](00_阅读指南_V1_2026-11-01.md#h-007a952fa375)，找到对应的页，照着用。

**第二步：记（用完之后）**

在那一节下面补一句：

```
> 【我用过】2026-XX-XX，跟 X 说的，实际说的是"……"，效果：……
```

**第三步：改（三次之后）**

同一个场景用过三次，回头看你记的三条。把手册里的话术，改成你自己真正会说的那个版本。

> **一条你说过三次、验证过的话术，比十条没用过的模板有价值。**
>
> 这本手册的最终形态，应该是 70% 你自己的话。现在它还不是。
