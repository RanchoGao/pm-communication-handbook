<a id="h-37005d842f1f"></a>

# 2. 搞清楚

> 话从对方流到我。这一步偷懒，后面全白干。

<a id="h-6a0ae0950c93"></a>

## 2.1 倾听

<a id="h-cd9b354564cc"></a>

### 先问自己 3 句

1. 对方说的是**事实**，还是他的**判断**？
2. 他现在带着什么**情绪**？
3. 他真正想要我做的那个**动作**是什么？

<a id="h-631f17f22e9b"></a>

### 结构化倾听：把一堆话拆成三块

对方说的每一段，都往这三个格子里塞：

| 格子 | 怎么认 | 例子 |
|---|---|---|
| **事实** | 能被验证的，有数字有时间 | "这个页面加载 8 秒" |
| **情绪** | 形容词、语气词、程度词 | "这个系统太难用了" |
| **期待** | 他想让谁做什么 | "你们能不能优化一下" |

**关键动作：把"情绪"翻译回"事实"。**

> 对方："你们这个系统太烂了。"
> 你心里翻译："某个具体操作让他受挫了，我得问出是哪一个。"
> 你嘴上说："我听出来这次体验让您挺不舒服的。能具体说说是哪一步卡住了吗？"

<a id="h-82ac92467e05"></a>

### 挖潜台词

表面一句话，底下常常压着别的东西。

| 他说 | 可能是 |
|---|---|
| "这个不着急" | "这个不重要"，或者"我不想现在讨论" |
| "我再看看" | 没被说服，但不想当面驳你 |
| "你们看着办" | "出了事别怪我" |
| "这个很简单吧" | 他在压你的排期 |
| "别人都能做" | 他在给你施压，未必真有别人 |

**挖法：问一个具体的。**

> "您说的'简单'，是指界面上加一个按钮，还是后台的计算逻辑也要改？"

一具体，虚的就露馅了。

<a id="h-d1483c5ba909"></a>

### 场景：对方甩来一堆图片/文档，什么都没说

> 可以直接抄：
> "收到了，我先看一下。
> 想先确认一下：您发这些过来，是想让我了解背景，还是有具体的事要我做？
> 如果有具体的事，能说一下期望的交付物和时间吗？"

两句话：**先确认目的，再确认交付物。**

<a id="h-a72ef18d9a0e"></a>

### 工具

- 重要会议**录音**（先征得同意），会后过一遍
- 手边一个本子，只记三样：**事实 / 情绪 / 待确认**

<a id="h-3681fd36fa76"></a>

### 别做这些

- ❌ 对方还没说完就开始想反驳 —— 你会漏掉后半段
- ❌ 只记"结论"不记"原话" —— 原话里才有潜台词
- ❌ 把对方的情绪当成事实来反驳 —— 越反驳越激化

---

<a id="h-3bb837ad975c"></a>

## 2.2 确认

> 确认的目的只有一个：**让对方相信你真的听懂了。**

<a id="h-e9cec11c66e6"></a>

### 先问自己 2 句

1. 我复述的，是他的**原话**，还是我的**理解**？
2. 有没有我自己脑补的部分？

<a id="h-575c6603707b"></a>

### 三步确认法

**第一步：复述事实**
> "我理解一下：现在是 A 系统在 B 场景下会出 C 问题，影响了 D 这批用户。对吗？"

**第二步：复述期待**
> "您希望的是在 X 之前把它修掉，同时不影响 Y。是这个意思吗？"

**第三步：主动暴露模糊点**
> "有两个地方我不确定：一是……二是……。您帮我确认一下。"

**第三步是关键。** 只做一二步，是"我听懂了"；做了第三步，是"我认真想过了"。对方的信任来自第三步。

<a id="h-978cdb99fb43"></a>

### 一句万能的确认句

> "我怕我理解偏，我复述一遍，您听听对不对——"

这句话的好处：**把"可能听错"的责任揽到自己身上**，对方不会觉得被质疑。

<a id="h-36f9237e35a2"></a>

### 别做这些

- ❌ "好的，明白了" —— 这不叫确认，这叫结束对话
- ❌ 用自己的话大幅改写对方的意思 —— 对方会觉得你在偷换概念
- ❌ 确认完不留记录 —— 过两周谁都不认

**确认完，补一条消息或一封邮件。** 白纸黑字，后面不扯皮。

<a id="h-9a462de18f73"></a>

## 2.3 了解他人

> 沟通前的功课。你对一个人了解多少，决定了你能影响他多少。

<a id="h-231158189aed"></a>

### 先问自己 3 句

1. 他的**考核**是什么？（他老板拿什么衡量他）
2. 他的**资源**边界在哪？（他能调动谁，不能调动谁）
3. 他上次在什么事上**发过火**？（那是他的雷区）

<a id="h-40e19559c01e"></a>

### 三副眼镜（尤其对领导）

领导看任何事，都戴着三副隐形眼镜：

| 眼镜 | 他在想 |
|---|---|
| **结果镜** | 这事能不能帮我交出成果？ |
| **风险镜** | 会不会让我背锅？ |
| **资源镜** | 投入产出值不值？ |

**你的每一次汇报、每一个提案，都要主动回答这三个问题。** 你不答，他就自己脑补，脑补出来的通常对你不利。

<a id="h-ddaabc596fa2"></a>

### 乔哈里窗：四个格子

| | 我知道 | 我不知道 |
|---|---|---|
| **他知道** | 公开区 | 盲区 |
| **他不知道** | 隐藏区 | 未知区 |

沟通的目标是**把公开区做大**。两个动作：

- **把我的隐藏区亮出来** → 主动暴露我的困难、我的顾虑、我的进度
- **把我的盲区问出来** → 主动求反馈："您觉得我这块哪里没做到位？"

**共识就是公开区。公开区越大，共识越多。**

<a id="h-1aa635cf431b"></a>

### 了解的渠道

工作场合能光明正大观察的：

- 他的周报/月报说了什么，没说什么
- 他在会上打断别人的是哪些话题
- 他转发的文章、发的朋友圈
- 他的老板在会上表扬他什么
- 他的上一个项目是怎么收场的

> ⚠️ 这里只谈职场公开信息。**不要碰对方的私人记录、聊天、账单。** 那是违法的，也毁关系。

<a id="h-6fccd4739873"></a>

### 别做这些

- ❌ 靠一次饭局就下结论说"他是 XX 型人"
- ❌ 把打听来的八卦当决策依据
- ❌ 在别人面前评价第三个人 —— 话一定会传回去

<a id="h-51449b6a764a"></a>

## 2.4 创造共识

> **开放性 = 扩大共识 + 消除盲区**
>
> 这一节是第 2 章和第 3 章的桥。听完了、说完了，共识不会自动出现，要专门造。

<a id="h-cb9d53cbfd12"></a>

### 先问自己 2 句

1. 我们现在的**共识区**有多大？（双方都认同的部分）
2. 我的**盲区**在哪？（他知道而我不知道的）

<a id="h-78cc709b44cb"></a>

### 共识是怎么变大的

回到 [乔哈里窗](#h-9a462de18f73)。共识区 = 公开区。它靠两个动作变大：

| 动作 | 做什么 | 一句话 |
|---|---|---|
| **我亮出来** | 主动暴露我的信息、顾虑、假设 | "我的判断基于三个假设：A、B、C。" |
| **我问出来** | 主动求对方的信息和反馈 | "有什么是我可能没看到的？" |

**大部分人只做第一个。** 只说不问，共识区只长一半。

<a id="h-bd29604ee07e"></a>

### 开放性的三个具体句式

| 场合 | 句式 |
|---|---|
| 讲完自己的方案 | "这是我的想法，你那边有什么我没考虑到的？" |
| 对方有不同意见 | "你这么看，一定有你的理由，说说看？" |
| 卡住了 | "我们先不争谁对，先把各自的依据摆出来。" |

**三句话的共同点：都是在邀请对方提供信息，不是在争对错。**

<a id="h-978956a9c91b"></a>

### 场景：对方是外行，听不懂我的专业内容

**共识的前提是听得懂。** 对方听不懂，就不可能有共识。

翻译的原则：**用他见过的东西打比方。**

| 技术说法 | 翻译 |
|---|---|
| "接口超时" | "两个系统说话，一方等太久没等到回话" |
| "并发问题" | "同一秒很多人一起操作，系统没排好队" |
| "数据不一致" | "两个地方记的账对不上" |
| "回归测试" | "改了一处，要把相关的地方都重新检查一遍" |
| "灰度发布" | "先让一小部分人用，没问题再全部放开" |

更多见 [8.4 对开发/测试](08_跟谁说_V1_2026-11-01.md#h-492c4ee4b264)，AI 辅助见 [附录 B.5.1](附录B_AI提示词库_V1_2026-11-01.md#h-85639e4b8d73)。

<a id="h-a4acef938605"></a>

### 场景：我的口语表达不够专业

反过来的情况：你要把随口说的，变成能进文档的。

> 提示词见 [附录 B.5.2](附录B_AI提示词库_V1_2026-11-01.md#h-6223b31b8d3a)。

<a id="h-db1fa7d4a9d1"></a>

### 别做这些

- ❌ 以为"我说了"就等于"达成共识了"
- ❌ 只说不问 —— 盲区永远消不掉
- ❌ 用术语压人 —— 对方听不懂就没有共识，只有服从
- ❌ 把"对方不反对"当成"对方同意"
