# 附录 A：模型速查卡

> 忘了某个模型是什么，翻这里。

<a id="h-b4291da9c4d0"></a>

## A.1 表达结构类

| 模型 | 展开 | 什么时候用 |
|---|---|---|
| **结论先行** | 结论 → 理由 → 数据/例子 → 建议 | 默认选项，汇报进展 |
| **PREP** | Point 观点 → Reason 理由 → Example 例子 → Point 重申 | 临时被点名，20 秒表态 |
| **SCQA** | Situation 情景 → Complication 冲突 → Question 疑问 → Answer 答案 | 正式提案、开场 |
| **FPA** | 事实 → 问题 → 建议 | 报坏消息 |
| **3W** | What → Why → How | 做分享、讲新东西 |
| **用户视角** | 场景 → 动机 → 阻碍 → 期望结果 | 讲需求、说服业务方 |
| **金字塔原理** | 结论 → 关键论点 → 详细信息 | 正式材料、书面报告 |
| **5W2H** | What / Why / Who / When / Where / How / How much | 分享工作、写方案 |
| **30 秒电梯** | 结论 + 一个数字 + 一个请求 | 走廊偶遇、临时汇报 |

<a id="h-9b80e9eaa11c"></a>

## A.2 沟通方法类

| 模型 | 展开 | 什么时候用 |
|---|---|---|
| **沟通漏斗** | 想 100% → 说 80% → 听到 60% → 听懂 40% → 做到 20% | 理解为什么会传丢 |
| **结构化倾听** | 事实 / 情绪 / 期待 | 听别人说话 |
| **乔哈里窗** | 公开区 / 盲区 / 隐藏区 / 未知区 | 分析共识和信息差 |
| **FFC 赞美** | Feeling 感受 → Fact 事实 → Compare 对比 | 夸人 |
| **GROW** | Goal 目标 → Reality 现状 → Options 选项 → Will 行动 | 辅导别人 |
| **ORID** | Objective 事实 → Reflective 感受 → Interpretive 意义 → Decisional 决定 | 复盘会、深度讨论 |
| **STAR** | Situation → Task → Action → Result | 讲一段经历、面试、答辩 |
| **RIDE** | Risk 风险 → Interest 利益 → Difference 差异 → Effect 影响 | 说服、提案 |

## A.3 场景步骤类

| 场景 | 步骤 |
|---|---|
| **三步破冰** | 双线定位 → 展现关切 → 把我的一部分交给他 |
| **四步反馈** | 确认需求 → 肯定合理性 → 我怎么行动 → 开放性结尾 |
| **四步道歉** | 我错在哪 → 给你造成了什么 → 我怎么补 → 以后怎么防 |
| **五步批评** | 控制环境 → 定义问题 → 刷新动作 → 设定反馈点 → 完成重启 |
| **五点交办** | 起点 → 终点 → 重点 → 卡点 → 节点 |
| **调解四步** | 释放情绪 → 处理情绪 → 重建目标 → 最小改善 |
| **说服三招** | 强准备 → 吹风慢熬 → 调整可变条件 |
| **导向行动三法** | 「来，我们来抓落实」→ 请对方给自己一个需求 → 绝不使用负面词汇 |
| **求助三原则** | 发起协作 → 让人帮得了 → 证明值得帮 |
| **施压回应** | 我做了什么 + 卡在哪 + 需要什么 + 接下来的动作 |
| **技术五件套** | 触发条件 → 系统行为 → 边界条件 → 异常分支 → 待确认点 |
| **跨部门五件套** | 目标 → 卡点 → 需要对方做什么 → 时间要求 → 完成标准 |

## A.4 金句

> 目标感的本质是方案力。

> 开放性 = 扩大共识 + 消除盲区。

> 建设性的本质是把沟通导向行动。

> 破冰不是展现自己，是给对方营造掌控感。

> 赞美 = 发现并指出对方的独特行为。九字箴言：轻轻地、深深地、常常地。

> 说服 = 说话有分量 + 击穿心理阈值。小火慢慢炖，火到猪头烂。

> 调解矛盾，不是解扣，而是补网。

> 闲谈 = 传递尊重 + 传递价值。

> 请示工作，必带方案。让领导做选择题，不做问答题。

> 艰难的沟通，把视角拉长到六个月后。

> 汇报：想清楚，干清楚，说清楚。
