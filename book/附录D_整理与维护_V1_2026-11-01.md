# 附录 D：这份手册是怎么整理出来的

> 给未来的自己看的。下次再整理知识库时，可以照这个方法。

<a id="h-45deed09c577"></a>

## D.1 原始材料

- 来源：个人笔记与工作记录
- 规模：432 个节点，最深 7 层，43 条备注
- 时间：整理于 2026-09-15

<a id="h-e1b3a849c1a8"></a>

## D.1.1 内容的使用与验证

本手册结合个人工作经验与学习笔记整理。参考话术应结合实际关系、职责和情境调整，并在使用中持续修订。第三方参考资料见附录 C。

## D.2 原始材料的三个问题

| 问题 | 表现 |
|---|---|
| **三类东西混在一起** | 方法论、真实困扰、AI 提示词，平铺在同一层 |
| **大量空壳** | 激励、辅导、提意见、绩效谈话、道歉、即兴发言、晋升答辩等只有标题没有内容 |
| **重复和堆积** | 多个"其他""待整理"节点，若干条目重复出现 |

<a id="h-57a3411e4d0f"></a>

## D.3 整理的四个原则

**一、按"我要做什么事"组织，不按"知识属于哪个学科"组织。**

因为这是一本**临场查**的手册，不是一本教科书。查询入口必须匹配你脑子里蹦出来的第一个词。

**二、每一页统一成同一个结构。**

```
先问自己 N 句（判断题）
→ 走哪条路（分岔表）
→ 每条路的具体步骤
→ 可以直接抄的话
→ 别做这些
```

**判断题在最前面**，因为沟通没有万能话术，只有匹配情境的话术。先判断，再选话。

**三、空的场景全部补齐。**

原始知识库里 20 多个只有标题的场景，按同样的结构整理完整。

**四、原始素材尽量保留。**

- AI 提示词按原文保留在附录 B，只做分类
- 原始的真实困扰全部保留在第 7 章，并整理应对方法
- 书里的原句（如"轻轻地、深深地、常常地"）保留原文

<a id="h-2f496d297da0"></a>

## D.4 怎么维护

**加新内容的时候：**

1. 先问：这是**方法**、**场景**，还是**提示词**？
2. 方法 → 附录 A；提示词 → 附录 B；场景 → 第 2-6 章找对应的筐
3. 真实遇到的具体困扰 → 第 7 章，并在 [0.2 速查表](00_阅读指南_V1_2026-11-01.md#h-007a952fa375) 加一行

**用完一次之后：**

在对应的场景下补一句：**"这次实际怎么说的，效果如何。"**

> 手册的价值不在于写得多全，在于**被用过多少次并且被改过多少次**。
> 一条被验证过的话术，胜过十条没用过的模板。
